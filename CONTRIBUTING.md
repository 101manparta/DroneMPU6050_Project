# Kontribusi

Terima kasih atas minat Anda berkontribusi pada project DroneMPU6050!

## Cara Berkontribusi

1. Fork repository ini
2. Buat branch baru: `git checkout -b fitur/nama-fitur`
3. Lakukan perubahan dan commit: `git commit -m "Menambahkan fitur XYZ"`
4. Push ke branch: `git push origin fitur/nama-fitur`
5. Buka Pull Request

## Pedoman

- Ikuti gaya kode yang ada
- Tambahkan komentar untuk fungsi baru
- Pastikan kode dikompilasi tanpa error
- Update dokumentasi jika diperlukan

## Laporan Bug

Silakan buka [Issue](https://github.com/101manparta/DroneMPU6050_Project/issues) dengan deskripsi yang jelas.
